## ⚡ What is OmniData Cleaner?
Say goodbye to Excel freezing when merging 100+ CSVs or dealing with broken character encodings (`mojibake`). **OmniData Cleaner Pro** is a standalone, fast desktop application built for data analysts, e-commerce managers, marketers, and researchers.

### 🌟 Key Capabilities:
- ⚡ **Batch Multi-File Merge**: Merge hundreds of CSV/TSV/TXT exports into a single master sheet in one click.
- 🔍 **Auto-Encoding Detection**: Seamlessly fixes garbled text (supports UTF-8, UTF-8-BOM, GB18030, and Latin-1).
- 🧹 **Intelligent Data Sanitization**: Fast whitespace trimming, line-ending normalization, and empty row removal.
- 🎯 **Deduplication Engine**: Eliminates redundant records across all imported files automatically.
- 💾 **Universal Export**: Export sanitized datasets to Excel-ready UTF-8 BOM CSV or structured JSON.
- 🖥️ **Live 50-Row Preview**: Inspect the transformed dataset before exporting.
